# Publicar con GitHub Desktop

El repositorio ya incluye un primer commit en la rama `main`.

1. Extrae `experimentos-github.zip` conservando la carpeta `experimentos`.
2. Abre GitHub Desktop.
3. Selecciona **File → Add local repository**.
4. Elige la carpeta `experimentos` extraída.
5. Pulsa **Publish repository**.
6. Usa el nombre `experimentos`, deja vacía la organización y desmarca
   **Keep this code private**.
7. Comprueba que el propietario mostrado sea `jaiciriaco` y publica.

El `.gitignore` impide añadir perfiles del navegador, sesiones, materiales de
la UNED, ZIP de copias, manifiestos, logs y el `config.json` local.
